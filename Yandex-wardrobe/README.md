## 📱 Описание проекта
Мобильное приложение для iOS "Онлайн-гардероб" - интерактивный конструктор образов с возможностью виртуальной примерки одежды.

## 🚀 Основной функционал
- **Конструктор образов** - создание комбинаций одежды
- **Виртуальная примерка** - примерка образов на фото пользователя
- **Персональный гардероб** - сохранение и управление образами
- **Фильтрация вещей** - поиск по параметрам (цвет, тип, стиль)

## 🛠 Технические детали
- **Платформа:** iOS 15.0+
- **Язык:** Swift
- **Архитектура:** MVVM
- **UI Framework:** SwiftUI

## 📋 Тестирование
- **Тест-план:** Тест-план.xlsx - полный план тестирования функционала
- **iOS тесты:** Wardrobe/ - исходный код приложения для анализа

## 🎨 Ключевые экраны
1. **Мой Гардероб** - главный экран с сохраненными образами
2. **Подбор Образов** - карусель для создания новых образов
3. **Фильтры** - поиск и фильтрация вещей
4. **Создание Образа** - конструктор комбинаций

## 📊 Метрики проекта
- Конверсия в покупку образов
- Время создания образа
- Количество сохраненных образов
- Активность пользователей гардероба
